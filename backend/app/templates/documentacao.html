Base URL

{{ base_url }}

Use HTTPS em produção. Todas as respostas são JSON, salvo a interface web.

Formato das linhas

  • Cartão completo: PAN|MM|AAAA|CVV — ex.: 4111111111111111|12|2028|123
  • Hash: fingerprint SHA-256 (64 caracteres hex) para consulta direta
  • Separadores aceitos na linha: | ; , : / \ e tab
  • Amex: 15 dígitos (34/37) com CVV de 4 dígitos

POST/api/check

Verifica um lote de linhas. Com record: true (padrão), grava novos e incrementa tentativas.

Corpo (JSON)

{
  "vulgo": "Minha Store",
  "lines": [
    "4111111111111111|12|2028|123",
    "5502093421123456|03|2029|456"
  ],
  "record": true
}

Resposta

{
  "total": 2,
  "new": 1,
  "known": 1,
  "duplicated": 0,
  "invalid": 0,
  "items": [
    {
      "line": 1,
      "status": "new",
      "masked": "411111******1111",
      "cc_full": "4111111111111111|12|2028|123",
      "fingerprint": "a1b2c3...",
      "is_retest": false,
      "attempts": 1,
      "expiry": "12/2028",
      "expired": false,
      "vulgo": "Minha Store"
    },
    {
      "line": 2,
      "status": "known",
      "masked": "550209******3456",
      "cc_full": "5502093421123456|03|2029|456",
      "is_retest": true,
      "added_on": "2026-09-20",
      "days_since_added": 3,
      "attempts": 4,
      "vulgo": "Out**"
    }
  ]
}

status por item: new, known, duplicated, invalid.

Exemplos

cURL

curl -s -X POST {{ base_url }}/api/check \
  -H "Content-Type: application/json" \
  -d '{
    "vulgo": "Bot Telegram",
    "lines": ["4111111111111111|12|2028|123"],
    "record": true
  }'

Python

import requests

resp = requests.post(
    "{{ base_url }}/api/check",
    json={
        "vulgo": "Bot Telegram",
        "lines": ["4111111111111111|12|2028|123"],
        "record": True,
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()
for item in data["items"]:
    print(item["line"], item["status"], item.get("cc_full") or item.get("reason"))

JavaScript (fetch)

const resp = await fetch("{{ base_url }}/api/check", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    vulgo: "Painel Web",
    lines: ["4111111111111111|12|2028|123"],
    record: true,
  }),
});
const data = await resp.json();
console.log(data.items);

Erros HTTP

  • 400 — corpo inválido ou vulgo vazio
  • 422 — JSON fora do schema esperado
  • 500 — falha interna (banco indisponível, etc.)
