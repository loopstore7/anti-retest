Visão geral

Todas as rotas respondem JSON. Use HTTPS em produção.

Base URL
{{ base_url }}

Envie um lote de linhas para /api/check: números inéditos entram na base e os já conhecidos voltam com a data do primeiro registro e o total de consultas.

Formato das linhas

Cada item de lines representa um cartão.

Cartão completo 4111111111111111|12|2028|123 número|mês|ano|cvv — ano com 2 ou 4 dígitos.
Hash SHA-256 9f86d081884c7d65…0f00a08 Fingerprint com 64 caracteres hexadecimais.
Separadores aceitos | ; , : / \ tab Espaços, pontos e hífens dentro do número são ignorados.
American Express 371449635398431|07|2030|1234 15 dígitos (34 ou 37) com CVV de 4 dígitos.
POST /api/check Verifica um lote de linhas

Com record: true (padrão), grava os números novos e incrementa as tentativas dos já existentes. Use record: false para apenas consultar.

Exemplos

Chamada a /api/check nas linguagens mais comuns.

curl -s -X POST {{ base_url }}/api/check \
  -H "Content-Type: application/json" \
  -d '{
    "vulgo": "Bot Telegram",
    "lines": ["4111111111111111|12|2028|123"],
    "record": true
  }'
import requests

resp = requests.post(
    "{{ base_url }}/api/check",
    json={
        "vulgo": "Bot Telegram",
        "lines": ["4111111111111111|12|2028|123"],
        "record": True,
    },
    timeout=120,
)
resp.raise_for_status()
for item in resp.json()["items"]:
    print(item["line"], item["status"], item.get("reason"))
const resp = await fetch("{{ base_url }}/api/check", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    vulgo: "Painel Web",
    lines: ["4111111111111111|12|2028|123"],
    record: true,
  }),
});
const data = await resp.json();
console.log(data.items);
